# AI 광고 대행사 — 7인조 캠페인 생성

사용자가 브랜드·목표·타겟을 입력하면, 7명의 AI 팀원이 순서대로(그리고 병렬로) 캠페인 바이블을 완성한다.

## 입력 확인

사용자 메시지에서 아래를 파악한다. 없으면 **한 번만** 물어본다:
- **브랜드**
- **캠페인 목표**
- **타겟**

형식 예: `네이버 클로바X | AI 교육 서비스 런칭 홍보 | 20~30대 직장인`

## 워크플로우 (반드시 이 순서)

### STEP 1 — AE 기획 (순차)
`ad-ae` 서브에이전트를 실행한다.
- 브랜드·목표·타겟을 전달
- 결과를 `output/01_ae_plan.md`에 저장

### STEP 2 — 카피 (순차)
`ad-copywriter` 서브에이전트를 실행한다.
- `output/01_ae_plan.md` 내용을 함께 전달
- 결과를 `output/02_copy.md`에 저장

### STEP 3 — 4개 제작팀 (병렬, 동시 실행)
아래 4개 서브에이전트를 **한 번에 병렬**로 실행한다:
- `ad-image-team` → `output/03_image.md`
- `ad-video-team` → `output/03_video.md`
- `ad-outdoor-team` → `output/03_outdoor.md`
- `ad-creative-team` → `output/03_creative.md`

각 팀에 `output/01_ae_plan.md`와 `output/02_copy.md` 내용을 전달한다.

### STEP 4 — 대표 검수 (순차)
`ad-ceo-review` 서브에이전트를 실행한다.
- `output/` 폴더의 모든 산출물을 검수
- **총점 50점 이상** → STEP 5로 진행
- **50점 미만** → 미달 팀만 STEP 3 재실행 (최대 2회)

### STEP 5 — 캠페인 바이블 통합
`output/` 산출물을 하나의 문서로 통합해 `output/campaign_bible.md`에 저장한다.

## 진행 중 사용자에게 알릴 것

각 STEP 시작·완료 시 짧게 상태를 알린다:
- 📋 AE 기획 중… / 완료
- ✍️ 카피 작성 중… / 완료
- 🖼️🎬🏙️💡 4팀 동시 작업 중… / 완료
- 👔 대표 검수 중… / 통과 or 재작업
- 📗 캠페인 바이블 완성

## 원칙

- AE 없이 카피부터 쓰지 않는다 (방향이 엇나감)
- 4개 제작팀은 반드시 병렬 실행 (순차 실행 금지)
- 대표 검수 전에 바이블을 만들지 않는다
